# ② 클립 칸 · 그룹 칸 · 클립 도구 막대 — 화면 규칙

> 2026-10-09 CLAUDE.md 슬림화 2차에서 **원문 그대로** 옮겼다(4만 자 안쪽 유지). 지금도 유효한 규칙이다 — 이 기능을 고치는 세션은 먼저 읽는다.
> 새 규칙은 여기에 한 줄 더하고, CLAUDE.md 에는 ⛔/🔴 금지선만 요약한다.

- 🧩 **클립 도구 막대**(v0.5.94 · `clip-tb`): 고른 클립 위 ✂⧉📋🗑⊟ · 삽입/효과(없는 항목은 「준비 중」) · 선택+Del = 삭제. main 은 문장마다 **모든 줄 + 고른 표시**를 받아 음성까지 줄 경계에서 자르고 잇는다(`delete/copy/paste/merge-clips` · `_planMdEdits` 한 곳). `test:cliptb`.
- ☑ **클립 막대는 체크박스(그룹 칸 체크·Ctrl+A·검색 ☑ 모두 포함)로 고른 클립에만 뜬다**(v0.7.80 `chkSel`/`clipTbOk`) — 번호 클릭 선택에는 안 뜬다 · 🖱 **클립 오른쪽 클릭 메뉴 `.clip-ctx`**(Vrew 모양 · 안 만든 항목은 「준비 중」) · 큰 그림(`.rail-peek`)·다른 메뉴가 뜨면 막대는 CSS 로 숨는다(마지막 팝업만). 막대를 띄우는 테스트는 `.clip-chk` 로 고른다.
- 🎬 **② 클립 칸에서 도입부(영상이 들어가는 그룹) 클립은 노랑으로 칠한다**(v0.7.27 · `.cut.intro` ← `c.isIntro` · 선택·고치는 중 클립은 제 색 · 커서는 노랑 바탕 + 주황 테두리 — 상태색이 노랑에 묻히거나 띠에 구멍이 나지 않게 · `test:introtint`).
- 🧩 클립 도구 막대(z 72)는 **팝업(`.modal-bg.show`)이 떠 있으면 CSS 로 숨긴다**(v0.6.83 — z 를 내리면 자기 메뉴 바깥 클릭 막(69) 아래로 가 안 눌린다).
- 🏷 **② 목록의 「AI 고지」 꼬리표 = AI 고지 팝업(`aiPopEl` · 떠 있는 카드 · v0.7.33)** — 사용·문구·시간·서식·**자리 9칸(`placeAi`)** 이 `saveAiCfg` 로 곧바로 ① 칸에 · 문장 범위는 팝업의 「📍」 → `aiRangeReq` · `Cards` 안에서 App state 를 직접 부르지 말 것(prop 으로). 채널 편집 탭 이름은 「📝 자막」. 🔲 클립 막대는 **그룹의 첫 클립이면 클립 아래**(그룹 머리를 가리지 않게).
- ☑ **클립 번호 밑 체크박스(`.clip-chk` · v0.7.32)** = Ctrl+클릭과 같다(`capSel` 한 몸) · 번호 글자는 `.clip-no-n` — 번호를 다시 쓸 땐 이 span 만(칸 전체 textContent 금지) · 테스트가 번호를 누를 땐 `.clip-no .clip-no-n`.
- 🎞 그룹 칸 체크는 따로 상태가 없다 — **② 클립 선택(`capSel`)과 한 몸**(그룹의 클립이 모두 골라졌으면 체크 · v0.7.31) · 합치기 = 큰 번호부터 `merge-group` · 삭제 = `delete-clips` · ③ 이 열리면 이 칸은 접힌다.
- 🎞 **① 와 ② 사이 「그룹」 칸(`groupCol` · v0.7.30 · Vrew 씬 칸 모양)**: 번호·제목줄·그림·시각 + 길이 · 누르면 그 그룹 첫 클립(재생 중이면 멈춤) — 그룹 모양에 새 값을 쓰면 `rows`·`.pg-*` 에도(🔴 `MemoCut` 열쇠와는 별개).
- ▶ **재생은 TTS 를 안 만든 클립에서 멈춘다 · ② 칸의 클립·배경을 누르면 멈춘다 · 배경(카드 사이)을 누르면 가까운 클립이 골라진다**(v0.7.29 로이 · `api.isSmoke` 면 E2E 에선 기본 꺼짐 — 켜려면 localStorage `pm.stopNoTts=1`).
- ⌨ **Home/End = 마지막으로 클립(또는 클립 막대)을 눌렀으면 그 그룹의 첫·마지막 클립, 클립 밖을 눌렀거나 선택이 없으면 대본 첫·마지막 클립(`clipFocusRef` · v0.7.28) — 자막 칸을 열지 않고 클립을 고른다**(v0.7.24 로이 · `test:cliptbscroll`).
- 🧩 클립 도구 막대는 **고른 클립이 목록 칸 밖으로 스크롤되면 함께 사라지고 돌아오면 다시 뜬다**(로이 v0.7.28 — 옛 「가장자리에 남기」(v0.5.99)를 뒤집음. 「안 보인다」는 말은 이 때문일 수 있다 · v0.5.99 — 「기능이 사라졌다」로 보인다 · `test:cliptbscroll`). 막대가 안 보인다는 말은 코드가 지워졌다는 뜻이 아닐 수 있다 — 먼저 `test:cliptb` 로 있는지, 어느 조건(스크롤·자막 칸 열림·선택 풀림)에서 사라지는지 재현한다. 또 **E2E 는 `renderer/dist` 번들을 읽는다 — 화면 코드를 고쳤으면 `npm run build:renderer` 뒤에 돌린다**(안 하면 옛 화면을 검증한다).
- ↕ **클립 끌어 옮기기 = 번호 칸을 끌어 다른 클립 위/아래에**(v0.7.69 · 로이) — 끈 클립이 체크돼 있으면 고른 클립 모두, 아니면 그 하나 · main `move-clips` 한 곳(대본 한 번 고치기 · 되돌리기 한 번 · 음성 들고 감 · 그림·영상은 놓은 그룹 것) · 끄는 동안 표시는 DOM 클래스만(다시 그리지 않는다) · `test:clipmove`(⚠ Playwright `dragTo` 금지 — 마우스 단계별로).
- ⌨ **클립 키(Ctrl+X·C·V·Del)는 초점이 클립 체크박스(`.clip-chk`)에 있어도 받는다**(v0.7.70 — INPUT 이라 막혀 「체크하고 Ctrl+X 가 안 된다」였다) · 키 처리기의 INPUT 조기 반환을 고칠 땐 이 예외를 지킬 것(`test:clipmove` [6]).
- ✂ **그룹 나누기(`split-group-at`) · ➕ 그룹추가(`add-group`)**(v0.7.71 · 브루 「씬 나누기·씬 추가」) — 클립 사이 호버 막대의 ↕(그룹 마지막 클립 아래엔 없음 · 문장 한가운데면 문장도 줄에서 나뉘고 .md 갱신) · 그룹 칸 단추는 🗑삭제 · ➕그룹추가 · ⤒합치기(이모지 위 · 글자 아래 · 스톡 단추 없음 — 스톡은 리본 이미지·비디오 탭) · 새 그룹은 자리표시 문장 + 빈 그림·프롬프트 · `test:groupops`.
- ＋ **클립 사이 호버 막대(`.clip-gap`)**(v0.7.72 · 브루) — 클립 아래 틈에 마우스를 가져가면 「＋ 클립 추가」(팝업: AI 목소리 클립만 동작 · 나머지 준비 중) + ↕ 그룹 나누기(새 그룹 이름은 빈칸). 🔴 막대의 빈 자리는 카드 사이 빈 곳처럼 다룬다(`inGap` 예외 · 클릭 stopPropagation) — `test:cliptbscroll`·`test:groupops`.
- ＋ **클립 추가 4종**(v0.7.73) — AI 목소리·빈 클립 = 새 문장 + 글 통째 선택 편집 · 이미지·비디오 클립 = `add-media-clip`(파일 고르기 → 한 클립짜리 새 그룹 · 한가운데면 A·N·B 셋 · B 는 A 그림 복사 · `UNDO.batch` 로 되돌리기 한 번). 🩹 입력 잠김(네이티브 대화상자 뒤 키보드 초점 소실)은 `refocus-window` + 전역 confirm/alert 감싸기 + 입력칸 mousedown 자가 복구 — 이 셋을 지우지 말 것. 클립 작업 속도는 `test:perfclip`(960클립 · 화면 반영 ≈ 0.4초가 현재 기준).
