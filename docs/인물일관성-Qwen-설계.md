# 인물 일관성 설계 — Qwen-Image 2.1 Turbo (2026-10-10 초안)

> 상태: **설계안 — 코드 변경 없음.** 구현 전에 §5 의 시험(코드 안 건드림)으로 가능 여부를 먼저 가른다.
> 근거: [작업노트 2026-10](작업노트/2026-10.md) 「Qwen-Image 2.1 Turbo 추가」·「Qwen-Image-2.1 로컬 실험」·「나노바나나 인물 일관성」, `core/char-refs.js`, ComfyUI 0.39.1 `TextEncodeQwenImage21`.

## 1. 목표와 금지선

- **목표**: 같은 인물이 컷마다(그리고 회차마다) 같은 얼굴·체형으로 나온다. 단 **옷·나이·시선·구도는 장면을 따른다.**
- **속도**: Turbo 글 프롬프트 장당 약 18초(앱 경로 실측). 참조를 쓴 장면 **35초 이내**(+2배 미만)를 합격선으로 둔다(지난 실험의 Qwen 25스텝 + 시트는 90초였다).
- **금지선**: ⛔ 기존 Krea2·나노바나나 경로를 바꾸지 않는다(`test:charrefs` 27 유지) · ⛔ 참조 때문에 장면이 깨지면(옷·인원·구도) 켜지 않는다 · 🔴 **fail-open** — 시트·참조가 실패하면 조용히 글 프롬프트만으로 그린다(제작을 막지 않는다) · ⛔ 「같은 일을 하는 코드가 여러 곳」 금지 — 인물 뽑기·시트 관리는 `core/char-refs.js` 한 곳.

## 2. 지금 있는 것 (사실)

| 층 | 내용 | 엔진 |
|---|---|---|
| 글 카드 반복 | 대본 `> 🎨 〔일관성 앵커〕` 인물 카드 묘사를 장면 프롬프트마다 반복 | 모든 엔진(대본이 한다) |
| 시트 참조 | `parseCards`→`castFor`→시트(`<출력>/characters/<이름>.png`)→`directive`+`refParts` | **나노바나나(Gemini) 전용** |
| Qwen 참조 기능 | `TextEncodeQwenImage21` 의 `images`(최대 16장)·`vae`·`resolution` — 글 해석 모델이 참조를 **보고**(`images_vl`) 확산 모델에도 참조 잠재(`reference_latents`)로 들어간다 | 방금 추가한 Turbo 워크플로는 **참조 입력 없음** |

지난 실험(비터보·25스텝)의 문제: 얼굴은 닮지만 ① 옷이 시트로 샌다 ② 시선이 정면으로 ③ 대본에 없는 인물이 늘어난다 ④ 구도가 인물 쪽으로 붙는다 · 속도 90초. **Turbo(8스텝)·낮은 참조 해상도·게이팅으로 이게 줄어드는지는 미확인** — 이 설계의 핵심 가설이다.

## 3. 설계 (4층 — 아래층이 항상 바탕)

**L0 글 카드(현행, 변경 없음)** — 바탕. 참조가 꺼지거나 실패해도 이것으로 간다.

**L1 시트 참조** — 인물마다 시트 1장 → 장면에 보이는 인물(최대 **2명**)의 시트를 참조로 첨부.
- 시트는 **Turbo 자기 자신이 t2i 로** 만든다(장당 약 18초 · 0원). `sheetPrompt`(얼굴 큰 정면 + 작은 전신, 단순한 옷)를 그대로 쓰되 시험 결과에 따라 **얼굴만**으로 줄일 수 있다(옷 새기 방지).
- 사람이 `characters/<이름>.jpg|png|webp` 로 바꿔 넣으면 그 그림을 쓴다(현행 규칙 유지).
- 장면 지시문 `directive` 는 엔진별로 문구만 고른다: 「얼굴·눈썹·눈매·머리색·체형을 참조와 같게, 나이는 장면대로, 옷·머리모양·자세·표정은 장면대로」(Gemini 용을 재사용).

**L2 게이팅(속도·새기를 함께 줄이는 장치)** — 참조는 **얼굴이 크게 보이는 샷**에만 붙인다.
- 판정: 장면 프롬프트에 close-up / portrait / medium shot / 「half-length」 같은 낱말이 있고 사람 1~2명일 때. 원경·군중·풍경은 L0 만(얼굴이 작아 참조 이득이 거의 없고 시간만 든다).
- 실제 효과는 §5 시험에서 **샷 유형별로** 확인한다(가설).

**L3 인물은행(회차를 넘는 일관성)** — 삼국지·고전 시리즈처럼 같은 인물이 여러 회차에 나올 때. 시트를 `<출력>/characters/` 대신 **채널 공용 폴더**(예: `~/.priming-maker/char-bank/<채널>/<이름>.png`)에서 찾고, 없으면 만들어 거기에 둔다. 이름이 같아도 시대·나이가 다른 카드는 키에 `core` + 묘사 해시를 함께 쓴다. 경험은행(`로이은행`)과는 별개 — 그림 자산이다.

**L4 2패스 얼굴 맞춤(보류)** — 참조 없이 먼저 그린 뒤 편집으로 얼굴만 시트에 맞춘다. 지난 klein 실험에서 10장 중 2장 사고. L1 이 불합격일 때만 시험한다.

## 4. 구현 설계 (구현은 §5 시험 합격 뒤)

- `core/char-refs.js`: 엔진 중립 부분(`parseCards`·`castFor`·시트 경로·`directive`)은 그대로. **어댑터**만 둘: `refParts`(Gemini, 현행) · `refImages`(Comfy: `[{name, path}]`).
- `main.js` `_charRefsFor`: 지금은 `GI.loadConfig().charRefs` 와 Gemini 시트 생성에 묶여 있다 → **시트 만드는 함수**(`makeSheet(card)`)를 엔진별로 주입(Gemini → `generateImageToFile`, Qwen → `ComfyImage.textToImage`)하고, 켜는 설정은 엔진 무관 키 하나로 둔다(옛 `charRefs` 값은 그대로 읽는다 — 마이그레이션 없이 호환).
- `core/comfy-image.js`: `textToImage({ …, refs })` — 로컬 서버면 `/upload/image` 로 시트를 올리고, 그래프의 `TextEncodeQwenImage21` 에 `LoadImage` 노드를 **런타임에 덧붙인다**(`images.image_1…`, `vae` 연결, `resolution` 낮춤). 별도 `…_ref.json` 워크플로를 만들지 않는다(두 벌이 되어 어긋난다). 참조가 없으면 그래프는 지금과 **한 글자도 다르지 않다**.
- 캐시 키: 그림 캐시 키에 **참조 시트 파일 해시**를 넣는다(시트를 바꾸면 다시 그려야 한다). 장면 프롬프트 끝에 붙는 `directive` 는 이미 프롬프트에 포함된다.
- 로그: `👤 G15 인물 참조: 원술(Qwen)` · 시트 생성/실패 · 참조 건너뜀 사유(게이트).
- 제한: 클라우드(comfy.org)는 대상 아님(Turbo 이름이 「(로컬)」) · 아내 PC 는 메인 PC 서버로 가므로 `/upload/image` 도 그쪽으로 간다.
- 테스트: `test:charrefs` 확장(원문 함수 뽑아 실행) · 참조 있음/없음 그래프 비교(없으면 현행과 동일) · fail-open(시트 실패 시 글만) · 캐시 키 변화 · 게이트 판정표.

## 5. 먼저 할 시험 — 코드 변경 없음 (`_실험/char-ref-qwen/`)

같은 10장면([고전_1021]) + 원술편([고전_1008]) 6장면, 같은 시드. 시험용 서버(포트 8199)나 운영 서버 한쪽만.

| 조건 | 바꾸는 것 |
|---|---|
| A | 참조 없음(현행 Turbo) |
| B | 시트(현행 `sheetPrompt`) 1장, `resolution=1024` |
| C | 같은 시트, `resolution=512`(구도 끌림·시간 감소 기대) |
| D | 얼굴만 시트(옷 없음) + `resolution=512` |
| E | D 에서 지시문 강/약 비교 |

**채점**: 로이의 눈(얼굴 일치 · 옷/시선/인원/구도 새기 사고 수) + 장당 시간. **합격선**(제안): 얼굴 일치가 A 보다 분명히 좋고 · 새기 사고 10장 중 1장 이하 · 장당 35초 이하. 게이팅은 같은 결과를 샷 유형별로 나눠 본다.
**불합격이면**: L0 만 유지(지금 상태) + 필요하면 L4 시험. 시간 손해만 보고 끝나지 않게 시험 단계에서 가른다.

## 6. 단계

1. **P0 시험**(§5) — 반나절 · 코드 변경 없음 · 결과를 작업노트에.
2. **P1** Comfy 참조 지원 + Qwen 시트 생성 + 설정 일원화(+ 테스트).
3. **P2** 게이팅(L2) + 인물은행(L3).
4. **P3** 시트 확인·교체 화면(인물 시트 갤러리 — 마음에 안 드는 시트를 다시 뽑기).

## 7. 결정이 필요한 것 (로이)

1. P0 시험 진행 여부(권장 — 코드를 안 건드리고 가능 여부부터).
2. 합격선(위 제안 그대로 쓸지).
3. 인물은행(L3)이 필요한 시리즈가 어느 것인지(삼국지 외).

## 8. P0 시험 결과 (2026-10-10 · `_실험/char-ref-qwen/` · [고전_1021] 10장면 · Turbo 8스텝 · 1344x768)

| 조건 | 장당 | 결과 |
|---|---|---|
| A 참조 없음 | 16.3초 | 장면마다 얼굴이 다르다 · 구도는 가장 다양 |
| B 풀시트(얼굴+전신) 참조 해상도 1024 | 35.4초 | ⛔ 시트의 흰 배경 초상이 장면에 붙거나 인물이 겹친다 |
| C 풀시트 512 | 20.6초 | ⛔ 같은 사고(2·3·17·21번) |
| D 얼굴 시트 512 | 20.1초 | ✅ 얼굴 일관성 확실 · ⚠ 구도가 인물 클로즈업으로 쏠림 · 정면 응시 · 3번 소녀 2명 · 8번 나이 무시 |
| E D + 강한 지시문 | 20.3초 | D 와 같음 |
| F 나이별 얼굴 시트 + 인원수 고정 + 구도·시선 지시 | 20.6초 | 얼굴 ✅ · **인원·나이·구도·시선 사고는 그대로**(지시문으로 안 막힌다) |
| G F + 참조 해상도 384 | 18.6초 | F 와 같음(속도만 조금 빠름) |

- **얼굴 시트(D·E·F·G)는 얼굴 일관성에 효과가 분명**하고 속도 합격선(35초)은 모두 통과한다. 사고는 **프롬프트 지시로는 못 막는다** — 사고가 난 장면의 공통점이 있다: ① 원경/넓은 구도(1번) ② 어린 인물(16·14세 · 3·8번 — 나이별 시트를 만들어도 성인 얼굴로 끌린다) ③ 인물이 장면 중심이 아닌 컷.
- 그 3종을 빼고 보면(10장면 중 2·12·14·15·16·17·21 = 7장면) 얼굴 일관성이 좋아지고 새기는 시선이 정면에 가까워지는 정도다 → **게이팅이 이 설계의 핵심**이다. 합격선(사고 ≤1/10)은 **게이트가 제대로 걸러 낼 때** 통과한다.
- **막힌 곳**: 게이트 판정에 쓸 **샷 크기**가 대본에 안 적힌 장면이 많다(인물 있는 165장면 중 영상 프롬프트가 있어 샷 크기를 읽을 수 있는 것 51개 · 114개는 없음). 이미지 프롬프트 첫머리에 샷 크기 낱말(`wide shot` · `medium shot` · `close-up`)을 쓰게 하는 것이 가장 쉽다 → 아도나이로이 요청서(미발송 · 로이 확인 대기).

## 9. P1 구현 (2026-10-10 · v0.7.84 · 로이 「클로드가 판단해서 진행해줘」)

- `core/char-refs.js`: `agesIn`·`cardAge`·`shotOf`·**`refGate`**(샷 낱말 없음·원경·군중·3명 이상·18세 미만·카드와 10살 이상 차이 → 안 붙인다) · `faceSheetPrompt`(얼굴만) · `<이름>.face.png` · `qwenDirective`(참조 순서로 이름) · 최대 2명.
- `core/comfy-image.js`: `supportsRefs`(TextEncodeQwenImage21 있는 워크플로) · `applyRefs`(LoadImage → `images.image_N` · VAE · 해상도 384) · `textToImage({refs})` 가 로컬 서버에 `/upload/image` 로 올린다 · 실패하면 참조 없이(fail-open) · 참조가 없으면 그래프는 이전과 같다 · 설정 `charRefs`(기본 켬 · ⚙ ComfyUI 「👤 인물 일관성(Qwen)」).
- `main.js`: `_qwenRefsFor`(얼굴 시트를 같은 서버로 1회 생성 · 이상 그림이면 버리고 그 인물은 참조 없이) → `runComfyImages` 의 `genOne` 이 게이트 통과 장면에만 참조 + 지시문 · 끝에 `👤 인물 참조 n장 · 참조 없이 그린 인물 장면: …` · `_loadCards`·`_narrationOf` 는 나노바나나 경로와 공유.
- 남긴 것: 그림 캐시 키에 참조 여부가 들어가지 않는다(나노바나나 경로와 같은 동작 — 설정을 바꿔 다시 만들 땐 🔄) · 인물은행(L3)·시트 갤러리(P3)는 다음 단계 · 대본 쪽 샷 크기 낱말은 채널사업부 요청서 `요청서_채널사업부_인물샷크기_20261010.md`.
