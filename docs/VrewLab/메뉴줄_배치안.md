# Vrew 메뉴 줄 배치안 (2026-10-24 · 로이 확인 대기)

근거: [Vrew화면_관찰.md](Vrew화면_관찰.md) §1·§6(캡처 11장). 방침: Vrew 의 **배치·조작**을 따르고 Priming 전용 기능은 반드시 살린다(지도 §0·§3). 이 문서는 코드 전 설계안이다.

## 0. 한 줄 결론
- Vrew 의 **10개 탭 이름·순서를 그대로** 쓰고, Priming 전용은 **「제작」 탭 하나를 도움말 앞에 더해** 담는다.
- **출판·리모션은 탭이 아니라 「모드」다**(대본이 아니라 책·TSV 를 다루는 별개 세계 — 코드도 `세계`로 분리돼 있다). 모드 전환은 지금 헤더 왼쪽의 3분할 단추를 **메뉴 줄 오른쪽 위**로 옮기고, 출판·리모션 모드에서는 메뉴 줄이 그 모드 자기 탭으로 바뀐다.
- **⚡ 만들기**는 Vrew 의 파란 **「내보내기」 자리(맨 오른쪽 큰 단추)**에 둔다 — 같은 역할(최종 산출)이다.

## 1. 탭 배치 (롱폼 모드)

| 순서 | 탭 | 이름 | 출처 | 요점 |
|---|---|---|---|---|
| ① | 계정 | `로이구글`식 이름 | Vrew | 회원 이름·**크레딧**(Vrew 의 반원 게이지 틀) · 로그아웃 — 회원제 값으로 |
| ② | 파일 | Vrew | 열기·저장·**내보내기 모음**(여기에 유튜브 포함) |
| ③ | 홈 | Vrew | 자주 쓰는 것 모음(되돌리기·복사·합치기·나누기·글꼴·무음 줄이기) |
| ④ | 편집 | Vrew | 클립 선택·나누기·마커·찾아 편집 |
| ⑤ | 자막 | Vrew | 원고·자막 불러오기·복사·지우기·맞춤법·교정 |
| ⑥ | 서식 | Vrew | 글자·정렬·테두리·배경 등(지금 「서식」 메뉴) |
| ⑦ | 삽입 | Vrew | 텍스트·이미지·비디오·AI 이미지/비디오·음악·캐릭터 |
| ⑧ | AI 목소리 | Vrew | **Priming 음성 전체**(채널 목소리·참조음성·발음사전) |
| ⑨ | 템플릿 | Vrew | 프레임·템플릿(후순위 — 비워 두거나 로고·정보카드 틀) |
| ⑩ | 효과 | Vrew | 필터·확대·화면 전환·볼륨·**배속**·**켄번스**·배경색 |
| ⑪ | **제작** | **Priming 전용 신설** | 채널·큐·단계별 만들기·업로드 상태 |
| ⑫ | 도움말 | Vrew | 설정·업데이트·진단·단축키·**프로그램에 묻기** |

> 「제작」을 Vrew 탭 사이가 아니라 **도움말 바로 앞**에 두는 이유: 앞 10개는 Vrew 사용자가 아는 자리 그대로 → 따라 하기 쉽고, 우리 것은 한 곳에 모여 「여기부터가 Priming」으로 보인다.

## 2. Priming 전용 기능의 자리 (요청하신 6개)

| 기능 | 자리 | 이유·모양 |
|---|---|---|
| **채널** | ① 메뉴 줄 오른쪽 위 **채널 고르개**(검색 칸 왼쪽) + ⑪ 제작 ▸ 「채널 편집」 | 채널은 모든 작업의 전제(목소리·화풍·자막·폴더) — 항상 보여야 한다. Vrew 에는 없는 개념이라 헤더에 둔다 |
| **큐(작업 순서)** | ⑪ 제작 ▸ 「작업 순서」 + 오른쪽 칸 위쪽의 접이식 줄(지금 위치 유지) | 여러 대본을 줄 세우는 것은 Vrew 에 없다. 펼침 상태는 지금과 같게 |
| **⚡ 만들기 · ⏹ 중단** | 맨 오른쪽 **큰 청록 단추**(Vrew 「내보내기」 자리) + ⑪ 제작 ▸ 단계 버튼 | 최종 산출 = 내보내기와 같은 위치·크기. 진행 중엔 「중단」으로 바뀜 |
| **유튜브** | ② 파일 ▸ 「내보내기」 묶음의 **「유튜브 올리기·예약·썸네일 마무리·챕터」** + ⑪ 제작 ▸ 업로드 확인표 | Vrew 의 「영상으로 내보내기·다른 형식으로 내보내기·썸네일 생성」과 같은 무리라 파일 탭에 붙인다 |
| **출판** | **모드 전환**(오른쪽 위) → 출판 모드의 자기 탭 | 책(POD)은 영상과 세계가 다르다(§3) |
| **리모션** | **모드 전환** → 리모션 모드의 자기 탭 | TSV → 음성·그림. 같은 이유 |

### 모드 전환 모양
`[ 롱폼 | 리모션 | 출판 ]` 3분할 단추 그대로, 위치만 **왼쪽 로고 곁 → 메뉴 줄 오른쪽 위(설정 아이콘 왼쪽)**. 모드가 바뀌면 **메뉴 줄 탭이 그 모드 것으로 교체**:
- 출판 모드 탭(안): 파일 · 홈 · 구조·정보 · 판권 · 표지·조판 · 등록·유통 · 도움말 (지금 출판 4탭을 그대로 흡수)
- 리모션 모드 탭(안): 파일 · 홈 · 음성(TSV) · 그림 · 영상 · 도움말

## 3. 지금 Priming 리본 → 새 자리 (옮겨 담기 표)

| 지금 | 새 자리 |
|---|---|
| 대본·음성 ▸ 📂 열기 · 오늘 대본 | ② 파일(열기) · ⑪ 제작(오늘 대본) |
| 대본·음성 ▸ 배속 · TTS · 삭제 · 발음사전 · 음성 설정 · 다시 연결 | ⑧ AI 목소리 |
| 대본·음성 ▸ 분할(H3 · 짧은/긴) | ⑤ 자막(분할) |
| 대본·음성 ▸ 모니터 끄기 · 다운로드 · 대본 보기 · 작성 기준 | ⑫ 도움말 · ⑪ 제작(다운로드·STT) · ⑤ 자막(대본 보기) |
| 이미지 ▸ 도구·화풍·생성·재생성 | ⑦ 삽입(AI 이미지) + ⑪ 제작(단계 버튼) |
| 비디오 ▸ 도구·범위·생성 | ⑦ 삽입(AI 비디오) + ⑪ 제작(단계 버튼) |
| 완성 ▸ .vrew · MP4 · 화이트보드 · 업로드 | ② 파일 + 큰 「만들기」 단추 |
| 서식 | ⑥ 서식 |
| 삽입(로고·삽입 영상·오디오) | ⑦ 삽입 · ⑨ 템플릿(로고) |
| 헤더 ⚙ 설정 · 검색 · 초기화 · 업데이트 ⟳ | 메뉴 줄 오른쪽 위 아이콘들(Vrew 와 같은 자리) · 초기화는 ⑪ 제작 |

(이미지·비디오·완성 리본의 낱낱 항목은 구현 때 코드로 다시 전수 확인 — 이 표는 큰 그림.)

## 4. 같은 기능을 두 탭에 두는 규칙
Vrew 가 홈·편집에 같은 단추를 겹쳐 둔 방식을 따른다(자주 쓰는 것 = 홈). 단 **실제 처리 함수는 한 곳**(지금 `clipMerge`·`clipSpeedSet` 처럼) — 단추만 두 번 그린다. 새 탭을 만들 때 기능을 복사하지 않는다.

## 5. 「준비 중」 단추
이미 45개쯤 있는 자리 중 **Vrew 에도 있는 것은 이 배치 그대로 유지**, Priming 에서 안 쓸 것(모바일 전송·Vrew 계정 요금 등)은 **만들지 않는다**(지도 §4 대체).

## 6. 단계 (제안)
1. **틀만**: 메뉴 줄(탭 이름 12개 + 오른쪽 위 아이콘·모드 전환·채널 고르개·큰 만들기 단추) + 탭 전환. 리본 안은 지금 것을 **새 자리 표대로 재배치**(기능은 그대로 · 동작 회귀 0 — 기존 E2E 의 선택자가 많이 걸리므로 먼저 `data-testid` 대조표를 만든다).
2. **홈·편집·파일 탭**: Lab A단계 결과(무음 줄이기·나누기·복사·배속)를 단추로.
3. **서식·자막 탭**: 지금 서식 패널 재배치(글꼴·크기·글자색은 홈 리본에도).
4. **모드별 탭**(출판·리모션) 교체.
5. 계정·크레딧 화면(§관찰 3).

## 7. 로이가 정해 주실 것
1. 「제작」 탭을 **도움말 앞(권장)** vs Vrew 탭 사이 vs 맨 앞.
2. 모드 전환을 **오른쪽 위로 이동(권장)** vs 지금 왼쪽 유지.
3. 유튜브 업로드를 **파일 탭(권장)** vs 제작 탭.
4. 템플릿 탭을 **비워 두기** vs 로고·정보 카드 틀로 채우기 vs 아예 빼기.
5. 지금의 4개 리본(대본·음성/이미지/비디오/완성)을 **없애고 위 표대로 흡수(권장)** vs 「제작」 탭 안에 그대로 보존(안전하지만 Vrew 와 덜 닮음).

⚠ 큰 일이다: 5번을 흡수로 하면 `test:ribbonlead`·`test:groupops`·`test:cliptb` 등 리본 선택자에 걸린 시험이 많이 바뀐다 — 1단계에서 대조표 + 시험 선택자 일괄 갱신을 함께 한다.
