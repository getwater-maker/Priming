## 2. 색·모양 (캡처에서 잰 값 — 근사)
- 완전 **다크 테마**: 메뉴 줄 `#151515` · 바깥 판 `#27292b` · 카드 바탕 `#131615` · 카드 안쪽 `#1d1f20` · 칩 `#202322`.
- 강조색 = **청록~하늘색 계열**(선택 테두리 어두운 청록, 단추 `#33a2b3` 쪽, 내보내기·씬 추가 단추는 더 밝은 하늘색).
- 글꼴 Pretendard · 카드 모서리 둥글게(약 8px) · 카드 사이 간격 넓게 · 선택된 카드 = 청록 테두리.
- Priming 은 **따뜻한 크림/베이지 라이트**(`--bg #faf6f0` 등) — 동일화하려면 `:root` 토큰 값을 다크로 바꾸고 **하드코딩 색(아직 약 200곳)을 토큰으로 더 옮겨야** 한다.

## 3. 02 · 계정·크레딧 화면
계정 카드(이름·이메일·설정·로그아웃) → 내 요금제(무료 · 기간 · 업그레이드) → 내 크레딧(반원 게이지 200/200 · 다음 충전일 · 새로고침) → 크레딧 사용 내역(필터·기간). Priming 의 회원 크레딧(`license.pointsOf`·「크레딧」 표시)을 이 틀로 보여 줄 수 있다 — **Vrew 계정·요금은 따라 하지 않고 우리 회원제 값으로.**

## 4. 동일화에서 가장 큰 구조 차이 (결정 필요)
1. **메뉴 줄 + 홈 리본 구조**(파일/홈/편집/자막/서식/삽입/AI 목소리/템플릿/효과/도움말) ↔ Priming 의 제작 단계 리본. → 메뉴 줄은 새로 얹고, Priming 전용(채널·큐·⚡만들기·유튜브·출판·리모션)은 **어느 메뉴에 둘지** 정해야 한다.
2. **씬 목록 칸**(가운데) — Priming 의 「그룹」과 대응. 칸을 새로 둘지, 그룹 칸을 이 모양으로 바꿀지.
3. **클립 카드 모양**(칩 줄 + 자막 줄 + 썸네일/시각)은 Lab 의 ② 클립 칸이 이미 비슷 — 모양만 다듬으면 된다.
4. **다크 테마 전환**(토큰 값 교체) — 가장 싸고 효과 큼.
