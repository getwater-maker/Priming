# 리본 선택자 대조표 (Vrew 메뉴 줄 1~2단계 · 2026-10-24)

메뉴 줄이 Vrew 11탭(`파일·홈·편집·자막·서식·삽입·AI 목소리·템플릿·효과·제작·도움말`)으로 바뀌면서 **옛 4개 리본(대본·음성 / 이미지 / 비디오 / 완성)이 흡수**됐고,
2단계에서 **리본 오른쪽 끝 상시 묶음(`rb-reader`)도 해체**됐다. `data-testid` 와 단추 기능은 **그대로**이고 자리(탭)만 바뀌었다 — 시험이 단추를 찾기 전에 **그 탭을 먼저 열어야** 한다.

## 0. 옛 위치 → 지금 탭

- **코드**: `pickMenu(옛이름)` 는 별칭을 받아 새 탭으로 간다(`Workspace.MENU_ALIAS`) — 메뉴 따라가기·`pickMenu('format')` 호환. 기본 탭 = `home`.
- **시험 도우미**: `test/_menu.js` — `menu(win, 'image')` 등 옛 이름을 그대로 받고, 새 이름(`caption`·`voice`·`help`·`make`…)도 받는다 · `byText(win, '이미지')` 는 옛 한글 메뉴 이름 클릭을 대신한다. `script` 별칭은 `home` — **TTS·발음사전·음성 설정을 쓰는 시험은 `voice`, 대본 보기는 `caption`, 다운로드는 `make`, 크레딧·모니터 끄기·작성 기준은 `help` 를 먼저 연다.**
