# 리본 선택자 대조표 (Vrew 메뉴 줄 1단계 · 2026-10-24)

메뉴 줄이 Vrew 11탭(`파일·홈·편집·자막·서식·삽입·AI 목소리·템플릿·효과·제작·도움말`)으로 바뀌면서 **옛 4개 리본(대본·음성 / 이미지 / 비디오 / 완성)이 흡수**됐다.
`data-testid` 와 단추 기능은 **그대로**이고 자리(탭)만 바뀌었다 — 시험이 단추를 찾기 전에 **그 탭을 먼저 열어야** 한다.

## 0. 옛 메뉴 이름 → 새 탭

| 옛 `data-menu` / 한글 이름 | 새 탭 | 비고 |
|---|---|---|
| `script` · 대본·음성 | `home`(홈) | 옛 대본·음성 전부(열기·오늘 대본·배속·TTS·발음사전·🔊 음성 설정·🔗 다시 연결·분할)를 한 탭에 그대로 |
| `image` · 이미지 | `make`(제작) ▸ `make-sub-image` | 제작 탭 이름표 칸에 세로 「② 이미지 / ③ 비디오」 전환 |
| `video` · 비디오 | `make`(제작) ▸ `make-sub-video` | 〃 |
| `finish` · 완성 | `file`(파일) | 📂 열기만 앞에 붙음(이름표 없음 · 1366px 한 줄 유지) |
| `format` · 서식 | `format` | 그대로 |
| `insert` · 삽입 | `insert` | 그대로 |
| (신설) | `edit` 편집 · `caption` 자막 · `voice` AI 목소리 · `template` 템플릿 · `effect` 효과 · `help` 도움말 | 1단계: 이미 있는 기능을 단추로 이음 |

- **코드**: `pickMenu(옛이름)` 는 별칭을 받아 새 탭으로 간다(`Workspace.MENU_ALIAS`) — 메뉴 따라가기(`core/menu-follow`)·`pickMenu('format')` 가 그대로 동작. 기본 탭 = `home`.
- **시험 도우미**: `test/_menu.js` — `menu(win, 'image')` 등 옛 이름을 그대로 받는다 · `byText(win, '이미지')` 는 옛 한글 메뉴 이름 클릭(`.menubar button:text-is(...)`)을 대신한다.
- **리본 오른쪽 끝 상시 묶음**(`rb-reader` = 🌙 모니터 끄기 · 📥 다운로드 · 📄 대본 보기 · 📘 작성 기준)은 모든 탭에 그대로(1단계는 옮기지 않음 · 2단계에서 자막/제작/도움말로).
