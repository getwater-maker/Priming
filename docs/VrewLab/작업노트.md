## P1 클립 시간 모델 — ⏩ 클립 배속 (2026-10-21)

**설계 판단**
- 조사(시간을 누적하는 곳 14곳)로 보니 **길이 = 음성 파일 실측(`ttsDurationSec`) 하나 · 시작 = 누적**이 이미 한 줄기다. 여기에 Vrew 식 `start/end/in/out` 필드를 따로 두면 두 벌이 된다(§8 단골 사고) → **따로 두지 않았다.**
  Vrew 의 「클립 in/out·speed」는 사본 체인으로 대신한다: `s.quiet = {key, src, srcDur, out}` = 원본(in/out 전체) → 처리(쉼·배속) → 사본(실측 길이).
- 나누기·합치기·지우기·붙이기는 **문장을 새로 만들어 따로 단 필드를 버린다**(조사 결과). 그래서 배속 기록은 「같은 글로 음성을 물려받을 때」만 함께 넘기고(`_editSentences`), 그 밖의 결과 조각은 **배속이 구워진 소리 그대로 · 배지 없음**(실측 길이라 시간은 맞다 · 되돌리려면 Ctrl+Z).
