## 효과 ③ 필터 구현 — CSS ↔ ffmpeg 한 표 (2026-10-25 · 설계 §3-2)

- **표 한 곳**: `core/clip-effects` 의 `FILTERS`(9종 — 흑백·세피아·따뜻하게·차갑게·선명하게·어둡게·밝게·빈티지·바랜 필름) = `params{gray,sepia,sat,hue,bright,contrast}` 하나에서 **CSS 문자열(`cssFilter`)과 ffmpeg 식(`ffmpegFilter`)을 둘 다 만든다**(CSS filter 함수 명세의 행렬 — `mGray/mSepia/mSat/mHue`).
- 🐞 **일치 시험이 진짜 버그를 잡았다**: 처음엔 단계들을 3×3 행렬 하나로 합쳐 곱했는데, CSS 는 **단계마다 0~255 로 자르므로** 「차갑게 × 순수 파랑」이 브라우저 238 ↔ ffmpeg 248 로 어긋났다(최대 차 10/255). 단계마다 `colorchannelmixer` 한 번씩(+ 마지막 대비 `lutrgb`)으로 바꾸자 **전체 최대 차 3/255**. `filterMatrix`(합성) 는 없애고 `filterStages` 로 교체.
- **굽기**: `clip-effects-bake.bakeFilter` — 원본(또는 **배경색 사본**) 크기 그대로 PNG 사본 `priming-fx/<지문>.png`(지문 = 원본 신원+필터+식). 같은 입력은 다시 굽지 않고 필터를 바꾸면 새 사본(옛 사본 그대로 → Ctrl+Z). 원본 불변.
- **빌더**: 이미지 그룹에서 **배경색(②) 사본을 먼저, 그 위에 필터 사본** — 띠(배경색)도 함께 필터된다. 이유 = 미리보기가 그림 `img` 요소에 `background-color` 와 `filter` 를 같이 걸어 요소 전체(배경 포함)가 필터되기 때문(범위가 같아야 미리보기 = 출력). 박스·켄번스는 사본 크기가 같아 그대로 맞는다. 렌더러 변경 없음.
- **미리보기**: `layerHtml` 이 img 에 `filter:${CEff.cssFilter(lk)}`.
- **메뉴**: 우클릭 ▸ 효과 ▸ 필터 · 클립 막대 · 효과 탭 「필터」 → 패널 `fl-panel`(없음 + 9종 · 각 버튼에 그 필터가 입혀져 미리 보인다 · 고르는 즉시 `set-group-look`).
