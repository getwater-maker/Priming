## 0. 방침 (로이 2026-10-24)

> Priming Lab 은 **Vrew 를 기준으로 같은 디자인을 만드는 것을 우선**하고, **기능도 Vrew 를 기준으로 같게** 만든다. 다만 **우리만 갖고 있는 기능은 반드시 포함**한다.

**제안하는 경계(로이 확인 필요 — §7 ①)**: 아래는 따르고, 아래 밖은 가져오지 않는다.
- ✅ 따른다: 화면 **배치·조작 방식**(어디에 무엇이 있고 어떻게 누르는가) · 기능 구성과 동작 · `.vrew` 파일 형식(호환) · 글꼴(Pretendard 는 공개 글꼴) · 일반적인 색 체계.
- ⛔ 가져오지 않는다: Vrew 의 **코드**(번들 소스) · **아이콘·일러스트·마스코트·로고 등 그림 자산** · **안내 문구 원문** · 「Vrew」 이름·브랜드. 같은 뜻이면 우리 말로 새로 쓴다. 이유: Priming 은 회원에게 파는 제품이다 — 겉모습과 자산이 같으면 분쟁 위험이 생긴다. (분석 문서 §8-7 의 「관찰한 동작·파일 형식만 참고」와 같은 선.)
- 서버가 필요한 기능(로그인·AI·클라우드)은 **똑같이 만들 수 없다** → 같은 쓰임을 우리 방식(kie·Claude·로컬)으로 §4.

## 3. Priming 만의 기능 — **반드시 유지**(방침)

동일화 작업이 아래를 지우거나 흔들지 않는다. 새 화면을 Vrew 모양으로 바꿔도 이 기능은 **같은 자리에 같은 힘으로** 남는다.

- **대본(.md) 중심 제작**: 대본 문법·파서(문장·문단·장면) · 「📘 작성 기준」 · 대본 보기/A4 PDF · 외부 수정 자동 반영
- **⚡ 만들기(큐 일괄 제작)** · 📅 오늘 대본 · 채널이 섞인 큐 · 「이번 편까지만」 · 시작 전 점검
- **채널 프리셋**(목소리·스타일·자막·로고·AI 고지·업로드·예약 한 묶음)
- **음성**: OmniVoice 참조음성 클로닝 · 유료 엔진 선택 · 숫자·전화번호 읽기 · 발음사전 · 문장 앞 들숨 제거 · 일본어·베트남어 역대조·루비
- **이미지·영상 생성**: kie 모델 · 인물 일관성 카드 · 화풍(스타일) · 무료 스톡 · 영상 범위(vidSel)
- **연출**: 정보 카드 · 화면 카드 · 막간 쉼 · AI 고지 · 채널 로고 · 켄번스 구간
- **출력**: 유튜브 MP4·화이트보드 MP4(.vrew 를 읽어 직접 굽기) · `.vrew` · SRT · 유튜브 업로드·예약·챕터·썸네일 마무리
- **출판**(POD PDF·ePub·부크크 등록) · **리모션**(TSV) · 다운로드·STT(yt-dlp)
- **로이 경험 마킹**(🟥·🟨 화자 규약) · 클립 수정 이력(🕘) · 회원제·크레딧·오류 로그
- **Lab 이 더한 것**: 세대 백업·복구 · 쉼 줄이기 · 클립 배속 · 막간 쉼 시각 일치 · 켄번스·자막 자리·로고 한 곳 규칙 · 단어 자리 맞추기 · 단어 지우기
