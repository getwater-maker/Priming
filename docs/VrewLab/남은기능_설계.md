# 남은 「비어 있는 기능」 설계 (2026-10-25)

> ✅ **구현 완료(2026-10-25)** — ①~⑥·⑨ 구현, ⑦ 녹음·⑧ FCPXML 은 로이가 필요 없다고 해 걷어냈다(결과·실측은 작업노트 각 절). 설계와 달라진 점: ⑥ 장면 점수는 **밝기 변화** 기준이라 색만 바뀌는 전환은 못 찾는다 · ⑨ 템플릿은 자막 서식을 담지 않았다.
>
> 기준: 지도(`Vrew동일화_지도.md`) ○ 항목 중 **새 의존성·모델 내려받기 없이** 만들 수 있는 것을 순서대로. 규칙은 지금까지와 같다 — 순수 규칙은 `core/` 한 곳 · 문장·그룹 필드는 마커·볼륨처럼 한 길로 · 굽는 것은 사본 · 시험은 실측.
> 합친 기반(원본 v0.9.118 포함)에서 시작한다(`이식_절차.md` §1).

## 만들지 않는 것 (이유)
| 항목 | 이유 |
|---|---|
| 배경 제거(DIS·BodyPix) | ML 모델이 필요 — 앱에 모델이 없고 `kie-models` 표에도 배경 제거 모델이 없다. 모델 내려받기는 **로이 허락이 필요한 일**이고 의존성 규칙(⛔ npm 늘리기)과 부딪친다 |
| AI 노이즈 제거(Resemble Enhance) · `arnndn` | 모델 파일 내려받기 필요 → **기본 노이즈 줄이기(`afftdn`, ffmpeg 내장)** 로 대신한다 |
| 모바일에서 불러오기 | 모바일 앱이 없다 |
| 캐릭터 삽입 | Vrew 의 AI 캐릭터 라이브러리 — 대응물 없음 |

## 만든다 (순서 = 작은 것·기반이 되는 것 먼저)
| # | 기능 | 방식 | 저장 | 핵심 시험 |
|---|---|---|---|---|
| ① | **본 그림 투명도·자르기** (① 칸 막대 「투명도」「자르기」) | 원본이 삽입 그림에 만든 `opacity`·`crop`(`overlay-look`·렌더러 `cropFilter`/`opq`)과 **같은 규칙**을 그룹 그림에도 — 그룹 `look.opacity`·`look.crop` → 빌더 트랙 `editInfo` · 렌더러(이미 안다) · 미리보기 | 그룹 look | 빌더→렌더러→화소(알파·잘린 영역) |
| ② | **기본 노이즈 줄이기** (효과/AI 목소리 탭 · 문장) | 문장 MP3 를 만들 때 `afftdn`(강도 약·중·강) — 볼륨과 같은 굽기 사본 · 원본 불변 | 문장 `s.denoise`(0~3) | 잡음 섞은 톤의 노이즈 플로어가 줄고 음성 대역은 유지(volumedetect·silencedetect) |
| ③ | **내 미디어 보관함 → 「내 이미지·비디오」** | 로이가 정한 폴더(⚙ 설정 📁)의 그림·영상을 격자로 보여 주고 고르면 삽입(=PC 불러오기와 같은 `overlay-op add`) | 설정 한 칸 | 폴더 목록·미리보기·삽입 |
| ④ | **효과음 패널** (검색·키워드) | 효과음 폴더(⚙ 설정 📁)를 훑어 파일 이름·폴더 이름 키워드로 찾고 미리 듣고 고른 클립 구간에 오디오 삽입 | 설정 한 칸 | 검색·삽입 |
| ⑤ | **이중 자막**(번역을 영상에 굽기) | 이미 만든 번역 SRT(`<이름>_<언어>.srt`)를 **둘째 자막 줄**로 — 렌더러(MP4)가 ASS 둘째 스타일로 첫 자막 아래에 · `.vrew` 는 자막 트랙이 한 벌이라 **MP4 만**(전환과 같은 옆 파일 방식) | 대본 `pr.dualSub{lang}` | MP4 프레임에 두 줄(화소) · 끄면 처음과 같음 |

| ⑧ | ~~FCPXML~~ | **폐기(같은 결정)** — 코드·시험 제거 | | |
