## 1. Lab 을 원본 최신으로 따라잡기 (✅ 완료)
- 원본은 Lab 이 갈라진 뒤 **23 커밋**(v0.9.96→v0.9.118) 나아가 있었다 → `git merge origin/main`(Lab 안) → **충돌 4곳** 해소.
  - `vrew-render.js` — 원본의 삽입 그림 자르기(`crop`)·불투명도(`opacity`)와 Lab 의 회전(`rot`)을 **모두** 살린다.
  - `App.jsx` — 원본의 삽입 그림·영상 세로 도구 막대 순서(`overlay-op order`)는 삽입 위층에, Lab 의 그룹 그림 순서(`look.layer`)는 본 그림에 — 한 메뉴에서 대상에 따라 갈린다 · 미리보기는 불투명도 + 확대·회전 함께.

- 이제 `vrewlab` 은 원본 `main` 을 **포함**한다 → 이식은 **빨리 감기(fast-forward)** 로 끝난다(충돌 없음). 그 사이 원본이 또 나아가면 이 1단계를 다시 한다.

## 3. 이식 본체 — 별도 폴더에서 (원본 `D:\Priming` 은 안 건드린다)
```powershell
git clone D:\Priming D:\Priming-port             # 원본의 깨끗한 복제(푸시 주소는 막는다)
cd D:\Priming-port
git remote set-url --push origin DISABLED
git remote add lab D:\Priming-VrewLab
git fetch lab vrewlab
git merge --ff-only lab/vrewlab                  # 1단계 덕분에 빨리 감기 — 안 되면 원본이 나아간 것(1단계 다시)
```
그 뒤 이식 폴더에서 **원본에 나가면 안 되는 Lab 전용 것**을 정리한다.

## 4. 올리기 (⛔ 로이가 「올려」 한 뒤에만)
1. **이식 전 태그**: 원본 `main` 의 현재 커밋에 `pre-vrewlab-v0.9.118` 태그를 달아 GitHub 에 올린다(기록만 남는 안전한 일 — 되돌릴 때 기준점).
2. 이식 폴더의 푸시 주소를 풀고 `git push origin main` (강제 푸시 ⛔).
3. 푸시 뒤 `npm run update:verify` 가 **「안전」** 을 찍을 때까지 「앱 다시 켜면 반영」이라고 안내하지 않는다(CDN 이 옛 매니페스트를 약 5분 준다).

5. `D:\Priming` 은 `git pull` 로 따라가고(작업 중이 아닐 때), 문제가 생기면 `D:\Priming-backup\README.md` §3 대로 **새 커밋으로** 되돌린다.
