**Priming – Privacy Policy** (Effective date: October 18, 2026)

Priming is a personal desktop application used by channel owners to publish videos they created on their own YouTube channel. It runs only on the user's own PC and has no server that receives YouTube data.

**YouTube API Services.** Priming uses YouTube API Services. By using Priming you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms). Google's Privacy Policy applies to data handled by Google: http://www.google.com/policies/privacy

**Permissions requested.**
- YouTube video upload (youtube.upload): to upload the user's own video, set its title, description, tags, the altered/synthetic-content disclosure, and an optional scheduled publish time.
- Read-only YouTube account access (youtube.readonly): to show the name of the connected channel, list the user's own playlists, and check for duplicate titles before uploading.
- Manage YouTube account items (youtube.force-ssl): only to set a thumbnail on the video just uploaded and to add it to a playlist chosen by the user.
No other data is requested. Priming never reads comments, subscribers, analytics, or any other person's data.

**How data is used.** Only to upload the user's own video to the user's own channel, to apply the thumbnail/playlist/schedule the user chose, and to confirm the result. Data is not sold, shared with third parties, or used for advertising.

**Storage and sharing.** The authorization token issued by Google is stored only on the user's PC, encrypted with the operating system's secure storage. It is never sent to the developer or any other server. Locally kept data is limited to the connected channel's ID and title, IDs of videos uploaded by the app, and the chosen playlist ID.

**Deletion and revocation.** Disconnecting a channel in the app (Settings → Channel connection) deletes the stored token. Access can also be revoked at any time at https://security.google.com/settings/security/permissions

**Compliance.** Priming's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
