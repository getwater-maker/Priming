# 요청서 — wise-priming: kie 호출 대행(회원 앱에 kie 키를 두지 않기) + 무상 포인트 만료

> 근거 정책: `docs/회원제-설계.md` §7-3 「최종 정책 7개」·「무상 포인트 회수」(로이 확정 2026-10-18). 포인트 표시·차감 RPC 는 `docs/요청서_wise-priming-포인트.md`(034 마이그레이션).

## 왜
- 회원이 「우리가 제공하는 API(kie)」를 쓰려면 **kie 키가 회원 PC 에 있으면 안 된다**(지금 앱은 키를 로컬 secret-store 에 둔다 = 관리자 전용). 키가 새면 로이의 선결제 크레딧이 한 번에 소진된다.
- 그래서 **서버가 회원 확인 → 포인트 차감 → kie 호출 → 결과 전달을 대행**한다. 앱은 kie 키 없이 서버에만 말한다.

## 무엇을 (Worker 또는 Edge Function — 기존 업데이트 중계 Worker 와 같은 인증 방식)
1. 엔드포인트(안): `POST /kie/image` · `POST /kie/video` · `GET /kie/task/<id>`. 헤더에 회원 토큰(기존 `no_token`/`invalid_token`/`not_member`/`expired` 응답 규칙 그대로) + 기기 id.
2. **가격은 서버가 가진다 — 앱이 보낸 금액·크레딧 값을 신뢰하지 않는다.** 앱은 `모델 id + 입력`만 보내고, 서버가 표(`core/kie-models` 의 모델·크레딧·영상 초당 값을 서버에 복제)로 차감량을 계산한다(정수 올림). 모르는 모델 id 는 거절.
3. 순서: 토큰 확인(사용권 만료면 거절) → `priming_points_spend`(ref = 시도마다 고유) → **잔액 부족이면 kie 를 부르지 않고 `no_points`** → kie `createTask` → 폴링 → 결과 URL 반환 → **실패·시간초과면 `priming_points_refund`**.
4. kie 키는 서버 비밀값(Secret)에만. 로그에 키·프롬프트 원문 전체를 남기지 않는다.
5. 남용 방지: 회원당 동시 작업 N건(안 3)·하루 상한(안 500pt) · 관리자 계정은 `charged=0` 그대로.
6. 결과는 **kie 의 URL 을 그대로 중계**(회원 PC 가 바로 내려받는다 — kie 생성물은 14일 뒤 삭제되므로 앱이 즉시 저장). 서버가 파일을 중간 저장하지 않는다.

## 무상 포인트 만료(원장 규칙)
- 사용권 구매·갱신 시 무상 100pt 를 원장에 `grant_free`(만료일 = 그 사용권 만료일)로 지급, 구매한 팩은 `grant_paid`(만료 없음).
- 잔액 계산에서 **만료일이 지난 `grant_free` 의 미사용분은 제외**하고, 만료 시점에 `expire` 행으로 회수 기록을 남긴다(화면 내역에 「기본 포인트 N 만료」).
- **차감 순서 = 만료가 가까운 무상분 먼저 → 유상**. 환불 대상은 유상 미사용분만(구매 7일 이내).
- 사용권을 갱신하면 새 무상 100pt 지급(기본값 · 이전 무상분 이월 없음).

## 운영 감시
- kie 계정 잔액(선결제) ≥ 회원 **미사용 유상 포인트 + 유효한 무상 포인트** 합계인지 주기 점검 → 부족하면 로이에게 알림. kie 에 잔액 조회 API 가 있는지 확인(없으면 관리자 화면에 로이가 잔액을 직접 입력).
- 사용 내역 조회 RPC(`priming_points_history`) 하나 — 앱 포인트 팝업용(차감·환불·지급·만료 내역).

## 로이가 먼저 할 일 (코드 밖)
- ✅ kie 재판매 확인 완료(2026-10-18 · kie 디스코드 지원팀): 「우리 백엔드·우리 키로 회원 대신 호출하고 자체 포인트로 과금」 허용 — 도매 할인·제휴는 없음. **이 요청서 진행 가능.** 지원팀 대화 캡처를 보관할 것(정식 계약서가 아님).
- 약관·구매 화면 문구(환불 7일·무상분 제외·무상 만료)와 선불전자지급수단 해당 여부는 전문가 확인.

## 앱 쪽 (서버가 준비된 뒤 Priming 세션이)
- kie 엔진 호출을 「로컬 키로 직접」과 「서버 대행」 중 선택(관리자는 직접 · 회원은 대행) · 엔진 목록에 `약 N pt/장` · 100pt 이상 작업만 시작 전 확인 · 부족하면 막고 「내 PC·내 키로 바꾸기」 안내.
