# 요청서 — wise-priming: 포인트 구매(결제) 페이지 + 원장 지급·환불

> 근거 정책: `docs/회원제-설계.md` §7-3 「최종 정책 7개」(로이 확정 2026-10-18). 짝 요청서: `docs/요청서_wise-priming-포인트.md`(원장·표시·차감·임의/이벤트 지급) · `docs/요청서_wise-priming-kie대행.md`(kie 호출 대행).

## 왜
회원이 **프로그램 안에서** 포인트를 사게 한다(kie 에는 로이가 카드를 등록해 자동 충전을 켜 둔다 — 회원 결제금이 그 비용을 채운다). 카드 정보를 앱이 다루지 않도록 **결제는 사이트 페이지**에서 한다.

## 흐름
1. 앱 포인트 팝업의 「포인트 구매」 → 기본 브라우저로 사이트 구매 페이지를 연다. 🔴 **URL 에 토큰·이메일·기기 id 를 싣지 않는다** — 앱이 서버에서 **일회용 코드(60초·1회)** 를 받아 `…/points/buy?c=<코드>` 로 열고, 사이트가 그 코드를 회원 세션으로 바꾼다(`priming_buy_ticket(p_device_id)` → `{ok, code}`).
2. 사이트가 포인트 팩 목록을 보여 주고 회원이 고른다 → **결제 전 약관 동의 체크**(환불 규정 · 무상 포인트 사용기한 만료 · 유상 포인트 무기한) → PG 결제창.
3. PG 가 결제 완료를 **서버로 알린다(웹훅)** — 사이트가 결제 id 로 PG 에 **다시 조회해 금액을 검증**한 뒤에만 지급한다(클라이언트가 보낸 완료 신호를 믿지 않는다).
4. 원장에 `grant_paid`(만료 없음)로 팩의 포인트를 기록 → 앱은 곧바로(결제 페이지가 닫히거나 앱이 포커스를 되찾을 때) 잔액을 다시 읽는다(`priming_license`, 평소는 5분 폴링).

## 포인트 팩
- 기준: **원가 1pt = $0.005, 판매 단가 = 원가 × 1.3 (약 $0.0065/pt)** — 원화 고정가 팩으로 판다(환율 변동은 로이가 가격표를 조정). **팩 구성·가격은 로이가 정한다**(관리자 화면에서 편집 · 팩 3~4단계 · 큰 팩일수록 단가를 낮추되 **어느 단계도 원가 × 1.2 아래로는 내리지 않는다**).
- 표시 가격은 **부가세 포함**. 결제 전 「1pt = 이미지 1장(기본 이미지 모델 기준)」 같은 환산 예시를 보여 준다(서비스 이름·달러는 화면에 쓰지 않는다).

## 환불 (정책 ⑤)
- **구매 후 7일 이내 · 미사용분만 전액** 환불(사용분 환불 불가) — 이벤트·임의·기본 지급(무상)은 대상 아님.
- 미사용 판정이 되도록 **유상 포인트는 먼저 산 팩부터(FIFO) 차감**하고(무상 → 유상 순), 원장이 팩별 잔량을 알 수 있게 `order_id` 를 단다. 일부만 쓴 팩은 「사용분 제외 잔량」 환불을 관리자 화면이 계산해 준다.
- 환불은 관리자가 주문 화면에서 실행 → PG 취소 + 원장 `refund` 행(포인트 회수). 7일 지난 요청·사용분은 화면이 막는다.

## 관리자 화면 (Priming 앱 → 주문)
- 주문 목록(회원·팩·금액·상태·결제 id·일시) · 팩 가격표 편집 · 환불 실행 · 기간별 매출 합계 · **kie 잔액 vs 회원 미사용 포인트 합계** 한 줄(감시는 kie 대행 요청서와 같은 값).

## 안전·정합
- **멱등**: 같은 결제 id 의 웹훅이 두 번 와도 지급은 한 번(`UNIQUE(payment_id)`).
- 결제 실패·취소는 지급하지 않고, 결제 성공인데 지급이 실패하면 재시도 큐 + 로이에게 알림(조용히 사라지지 않게).
- 카드 번호는 서버가 받지 않는다(PG 호스팅 결제창). 로그에 결제 토큰·개인정보를 남기지 않는다.
- 영수증: PG 영수증 링크를 주문 내역에 보여 준다. 현금영수증·세금계산서 필요 여부는 로이 사업자 유형에 따라(로이 확인).

## 로이가 먼저 정할 것 (코드 밖)
1. **PG 선택** — wise-priming 사이트가 이미 결제(강의·구독)를 받고 있으면 **그 PG 를 그대로 쓴다**(새로 가입하지 않는다). 없으면 국내 PG(예: 토스페이먼츠·포트원 등) 중 하나.
2. **팩 구성·가격표**.
3. 사업자 정보(통신판매업 신고·상호·사업자번호 표시) · **약관·환불 문구 · 선불전자지급수단 해당 여부 전문가 확인**(`docs/회원제-설계.md` ⑦).

## 앱 쪽 (서버가 준비된 뒤 Priming 세션이)
- 포인트 팝업에 「포인트 구매」 버튼(일회용 코드를 받아 브라우저로 열기) · 결제 후 잔액 즉시 갱신 · 내역 팝업에 구매·사용·환불·만료 · 이벤트 코드 입력 칸 · 부족하면 구매 안내(「내 PC·내 키로 바꾸기」와 함께).
